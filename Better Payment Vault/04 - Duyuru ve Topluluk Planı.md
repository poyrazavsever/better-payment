# Duyuru ve Topluluk Planı

Uygulama rehberi: [[Topluluk/Rehber - Duyuru ve Build in Public]].

## Amaç

Star toplamak kadar gerçek test hesabı, doküman bilgisi, tekrar eden contributor ve provider doğrulaması kazanmak.

## İçerik sütunları

1. Türkiye'de ödeme entegrasyonu neden zor?
2. Callback'e neden güvenilmez?
3. Provider akışlarının teknik farkları.
4. Sandbox doğrulama ve help-wanted çağrıları.
5. Haftalık release, issue ve contributor özeti.

## Duyuru öncesi kontrol

- Nightly sandbox yeşil.
- Provider güven seviyesi görünür.
- GitHub description/topics tamam.
- Web README projeye özgü.
- Katkı çağrıları küçük ve sahiplenilebilir.
